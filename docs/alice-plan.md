# План: Алиса → фильм на телевизоре

[English](alice-plan.en.md)

Цель: сказать Алисе на станции (например, «Алиса Мини») «посоветуй фильм», получить совет и командой «включи» открыть этот фильм на телевизоре в КиноПоиске, RUTUBE или VK Видео.

Статус: план, ничего не реализовано. Перед работой на ТВ прочитать [AGENTS.md](../AGENTS.md).

## Архитектура

```
Станция ──голос──▶ Яндекс Диалоги ──webhook──▶ облачная функция (навык)
                                                   │  поиск фильма (КиноПоиск API / RUTUBE)
                                                   ▼
                                             очередь команд
                                                   ▲  исходящее соединение (long-poll / WebSocket)
                                                   │
                                 служба на ТВ (APK, root) ──am start──▶ приложение
```

1. **Свой приватный навык Алисы** (например «Киновечер»). Весь разговор идёт внутри навыка: «посоветуй» → предложение фильма → «ещё» / «включи». Короткий вариант: «Алиса, попроси Киновечер включить Дюну».
2. **Облачная функция** (Yandex Cloud Functions или аналог): обрабатывает фразы, ищет фильм, кладёт команду в очередь.
3. **Служба на ТВ** — маленький APK (как `launcher/`, без AndroidX), сама держит исходящее соединение с облаком: проброс портов на роутере не нужен. Получив команду, будит экран и открывает фильм. На Android 7 запуск activity из фона разрешён (ограничение появилось в Android 10). Бюджет памяти — 10–15 МБ.
4. **Выбор приложения:** явно («на Рутубе») или по порядку КиноПоиск → RUTUBE → VK Видео. При нескольких кандидатах (фильм, трейлер, обзор) — список на экране ТВ, выбор голосом («второй») или пультом.

## Что выяснено

- **Контекст обычного разговора с Алисой не получить.** Сторонний навык не видит предыдущих реплик. [ha-yandex-station-intents](https://github.com/dext0r/ha-yandex-station-intents) реагирует только на заранее заданный список фраз (без подстановок). [YandexStation](https://github.com/AlexxIT/YandexStation): сказанную фразу узнать нельзя, текстовый ответ Алисы возвращается только для ограниченного набора (погода, время, умный дом). Поэтому совет должен давать сам навык.
- **Навык:** приватный навык проходит модерацию только имени активации и иконки. Имя — 2–5 слов, без «Яндекс», «Алиса», «Станция». Ответ навыка — за ~3 с, допускается не больше 1 ошибки сервера на 10 запросов ([требования](https://yandex.ru/dev/dialogs/alice/doc/ru/requirements)).
- **RUTUBE:** поиск сайта `GET https://rutube.ru/pangolin/api/web/v1/search/combined/video_playlist?query=<текст>&client=wdp&page=1` работает без авторизации, отдаёт `id` (32 hex), `title`, `duration` (с), `author.name`, `is_official`. Старый `/api/search/video/` возвращает пустой список. В выдаче много лишнего (трейлеры, музыка, фейки вроде «Интерстеллар 2 (2027)») — фильтр по длительности (≥ 60 мин) и автору, сомнительное — списком на экран.
- **КиноПоиск, поиск по названию:** неофициальный `kinopoiskapiunofficial.tech` (`/api/v2.1/films/search-by-keyword?keyword=`), нужен бесплатный ключ (`X-API-KEY`); без ключа `401`. Неофициальные API периодически ломаются.
- **VK Видео:** поиск через API VK требует пользовательского токена — скорее всего, только открытие экрана поиска в приложении.
- **Другие приложения:** только запуск или передача текста в их поиск, если они это принимают.
- **Риск:** VK Видео для Android TV 2.118 требует Android 9, на ТВ работает 2.22 — приложения на этой прошивке скоро нельзя будет обновлять, интеграции могут сломаться, когда сервисы перестанут поддерживать старые версии.

## Шаг 1: какие ссылки принимают приложения (на ТВ)

Какие ссылки (`VIEW` с `scheme/host/path`) и поисковые intent (`android.intent.action.SEARCH`, extra `query`) принимает каждое приложение, нигде не описано — проверяется только на ТВ.

PowerShell (VPN выключен):

```powershell
adb connect <IP ТВ>:5555
foreach ($p in 'ru.kinopoisk.tv','rtb.mobile.android','com.vk.tv') {
  "=== $p"
  adb shell "dumpsys package $p | grep -E 'Scheme|Authority|Path|Action:|android.intent.action.(VIEW|SEARCH)' | sort -u"
}
```

Затем пробные запуски, например:

```
adb shell am start -a android.intent.action.VIEW -d "https://rutube.ru/video/<id>/" rtb.mobile.android
adb shell am start -a android.intent.action.VIEW -d "https://www.kinopoisk.ru/film/258687/" ru.kinopoisk.tv
adb shell am start -a android.intent.action.SEARCH -e query "Интерстеллар" <пакет>
```

Итог — таблица «приложение → способ: ссылка на фильм / экран поиска с запросом / ввод нажатиями (`input text` под root, запасной вариант)».
