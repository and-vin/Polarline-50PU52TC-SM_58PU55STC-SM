# Служба «Киновечер» на ТВ

[English](README.en.md)

APK ~13 КБ без AndroidX: служба держит исходящий long-poll к очереди команд (облачная функция или `alice/devqueue.py`) и открывает фильмы. Проброс портов не нужен. Запускается после загрузки, после обрывов сети переподключается сама. Память — около 3 МБ PSS.

## Команды

| Команда | Что делает |
|---|---|
| `{"app": "rutube", "action": "open", "uri": "rutube://rutube.ru/video/<id>/"}` | ролик RUTUBE |
| `{"app": "vk", "action": "search", "uri": "vkvideo://video/search?query=<запрос>"}` | поиск VK Видео |
| `{"app": "kinopoisk", "action": "open", "uri": "kpatv://film?filmId=<hd_id>"}` | карточка КиноПоиска; выбор аккаунта подтверждается сам |
| `{"app": "kinopoisk", "action": "search_keys", "query": "<запрос>"}` | поиск КиноПоиска: латиница через `input text`, кириллица — нажатиями по клавиатуре приложения |
| `{"action": "ping"}` | проверка связи |

Протокол: `GET <url>/tv/poll` (`Authorization: Bearer <секрет>`) → 200 с командой или 204 через ~25 с; ответ `POST <url>/tv/ack` `{"id", "ok", "error"}`.

## Нажатия клавиш

Обычное приложение не может нажимать клавиши в чужих приложениях, а пользователь shell может. Поэтому служба подключается к adb самого ТВ (`127.0.0.1:5555`, его включает прошивка) со своим ключом RSA и выполняет `input ...`.

- При первом подключении на ТВ появляется «Разрешить отладку по USB?» для ключа службы — выбрать «Всегда разрешать с этого компьютера».
- adbd на Android 7 держит только одно TCP-подключение: пока к ТВ подключён компьютер (`adb connect`), служба не может нажимать клавиши (ссылки при этом работают). Отброшенное подключение остаётся висеть до перезапуска adbd.

## Сборка и установка

```
./build.sh <android-sdk> <jdk-17>          # build/tvagent.apk; ключ подписи в keystore/ (не в git)
adb install -r build/tvagent.apk
adb shell am startservice -n com.andvin.tvagent/.AgentService --es url <адрес очереди> --es secret <секрет>
```

Проверка без облака: на компьютере `python3 alice/devqueue.py --secret <секрет>`, адрес очереди `http://<IP компьютера>:8787`, команды — `curl -X POST <IP>:8787/send -H 'Authorization: Bearer <секрет>' -d '<команда>'`.
